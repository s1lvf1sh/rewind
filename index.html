    How it works
    

      
Record once, travel anywhere. The interpreter never changes the program's state directly. Every change is a write (a variable set, a list item stored, a call made, a line printed), and each write knows how to undo itself. Running records them all in order. Moving through time applies writes forward or undoes them backward, so any step can be reached exactly, without rerunning anything.

      
Every value remembers its ingredients. Each write also records which earlier writes its value was computed from (data flow), which ones chose where it was read from (list indexes), and which ones controlled whether the code ran at all (conditions). "Why?" follows these links backwards: through arithmetic, through function calls and returns, and through lists.

      
The language has numbers, strings, booleans, nil, lists, functions with closures, let, if/else, while, for x in list, break, continue and return. Built-ins: print len push pop range str abs floor sqrt min max. Conditions must be true or false; it will not guess.

      
Keys: ← → step, Shift+← → step over calls, Home/End, Ctrl+Enter to run. Click a line number to set a breakpoint.
